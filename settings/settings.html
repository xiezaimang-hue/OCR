⚙️ 設定

設定 Gemini API Key 與翻譯模型

Gemini API Key

此擴充功能使用 Google Gemini API 生成翻譯與例句。請到 Google AI Studio 取得免費的 API Key。

建議用 gemini-2.5-flash。若遇到 429 配額或 404 模型不可用，背景會自動 fallback 到其他模型；也可點「🔄 偵測可用模型」直接從你的 API Key 取回真實清單。

快捷鍵

預設為 Ctrl+Shift+O。 若要自訂，請前往 chrome://extensions/shortcuts 修改。

使用方式

  1. 在任何網頁上按 Ctrl+Shift+O 或右鍵選「啟用 OCR 選取」。
  2. 拖曳滑鼠框選一個英文單字。
  3. 等 1-3 秒，tooltip 會顯示翻譯，單字同時存入列表。
  4. 點右上角擴充圖示 →「開啟單字列表」查看與管理。
