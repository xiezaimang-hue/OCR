设定 Gemini API Key 与翻译模型

Gemini API Key

此扩展程序使用 Google Gemini API 生成翻译与例句。请到 Google AI Studio 获取免费的 API Key。

建议用 gemini-2.5-flash。若遇到 429 配额或 404 模型不可用，背景会自动 fallback 到其他模型；也可点「🔄 检测可用模型」直接从你的 API Key 获取真实清单。

快捷键

预设为 Ctrl+Shift+O。 若要自定义，请前往 chrome://extensions/shortcuts 修改。

使用方式

  1. 在任何网页上按 Ctrl+Shift+O 或右键选「启用 OCR 选择」。
  2. 拖动鼠标框选一个英文单词。
  3. 等 1-3 秒，tooltip 会显示翻译，单词同时存入列表。
  4. 点右上角扩展程序图标 →「打开单词列表」查看与管理。
